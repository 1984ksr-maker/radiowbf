## Hosting

Diese Website wird bei Cloudflare, Inc. gehostet. Beim Aufruf der Seiten verarbeitet Cloudflare technisch notwendige Daten wie die IP Adresse Ihres Geräts, um die Seite auszuliefern und vor Angriffen zu schützen (Art. 6 Abs. 1 lit. f DSGVO). Wir setzen keine Cookies und kein Tracking ein. Die Schriften werden von unserem eigenen Server geladen, nicht von Google.

## Livestream

Wenn Sie auf Play drücken, wird der Audiostream direkt von Airtime Pro (Sourcefabric) bzw. von unseren Partnersendern Subversive Radio und reboot.fm geladen. Dabei wird die IP Adresse Ihres Geräts an diese Anbieter übertragen. Die Programminformationen („Now playing“) werden direkt von Airtime Pro abgerufen, auch ohne dass Sie auf Play drücken.

Ob gerade ein Partnersender live ist, fragt unser Server bei Cloudflare ab. Dabei werden keine Daten von Ihnen an die Partnersender weitergegeben.

## Sendeplan

Der Wochenplan wird von unserem Server aus einem öffentlichen Google Kalender gelesen. Ihr Browser nimmt dabei keine Verbindung zu Google auf.

## Archiv: SoundCloud und Mixcloud

Unsere Sendungen liegen bei SoundCloud und Mixcloud. Die Vorschaubilder der Sendungen werden direkt von den Servern von SoundCloud geladen, dabei wird die IP Adresse Ihres Geräts an SoundCloud übertragen. Der eigentliche Player wird erst geladen, wenn Sie auf Play drücken. Es gelten die Datenschutzerklärungen von SoundCloud und Mixcloud.

## Instagram

Wenn auf der Startseite unsere neuesten Instagram Beiträge angezeigt werden, geschieht das über den Dienst Behold (behold.so). Die Bilder werden von dessen Servern geladen, dabei wird die IP Adresse Ihres Geräts übertragen. Ein Klick auf ein Bild führt zu Instagram, wo die Datenschutzerklärung von Meta gilt.

## Chat

Der Community Chat wird über Netlify, Inc. bereitgestellt und auf der Startseite sowie auf der Chat Seite eingebettet. Beim Laden des Chats wird die IP Adresse Ihres Geräts an Netlify übertragen. Was Sie im Chat schreiben, ist für alle Teilnehmenden sichtbar.
